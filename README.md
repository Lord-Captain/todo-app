This project is a simple full-stack project that helps tyros comprehend what does a full-stack project look like and how to get started.

How to run it?


First, open a terminal, run these bash codes:

cd server #suppose you are already in the root(todo-app/)

npm install #if you already install npm, skip this

npm run dev


Second, open another terminal while hold the first terminal. In the second terminal, run these bash codes:

cd client

npm run dev


Finally, access http://localhost:5173, then you can see a fully functional todo-app!
